# Enzora web application

Static frontend deployment for the Enzora research workspace.

Open https://yuzhangli2281.github.io/Enzora.github.io/ . The private model API requires a workspace access code. Demo mode is explicitly labeled and uses simulated data.

Application source and deployment documentation: https://github.com/YuzhangLi2281/Enzora (currently private).

The current API uses a temporary authenticated relay for integration testing. It has a finite cluster allocation and is not a permanent service. This repository contains no model weights or API keys.
